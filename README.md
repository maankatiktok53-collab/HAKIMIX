# HAKIMIX Framework 🛡️🔥

**HAKIMIX** waa Framework awood badan oo loo dhisay ardayda iyo falanqeeyayaasha amniga sayberka (*Cybersecurity Researchers & Students*). Waxaa diyaariyay **Hakimi**.

---

## ⚡ Astaamaha Gaarka ah (Special Utilities)

1. **🔤 Encoder, Decoder & Hash Toolkit (`[C]`):**
   - **Base64** Encode/Decode
   - **URL** Encode/Decode
   - **Hexadecimal** & **Binary** conversions
   - **Hash Generator**: MD5, SHA-1, SHA-256, SHA-512, iyo NTLM.

2. **📖 Common Ports & Protocols Encyclopedia (`[P]`):**
   - Qaamuus interactive ah oo ku saabsan dakadaha (Ports 21, 22, 25, 53, 80, 88, 110, 139, 161, 389, 443, 445, 1433, 3306, 3389, 5432, 5900, 8080, iwm.), adeegyadooda, amniga, iyo aaladaha lagu baaro.

3. **📡 Network Diagnostics & Listener Helper (`[N]`):**
   - **TCP Port Open Checker**: Hubinta tooska ah haddii dakad gaar ah furan tahay.
   - **Netcat & Socat Listener Generator**: Diyaarinta amarrada dhegeysiga dakadaha (`nc -lvnp`, `socat`).
   - **Local HTTP Server Builder**: Kicinta degdegga ah ee server Python ah.
   - **IP Address Lookup**: Ogaanshaha Local & Public IP.

4. **🔍 Raadinta Tooska ah (Search Engine - `[S]`):**
   - Baarista dhammaan aaladaha iyo 100+ amarro hal mar gudaheed.

5. **📁 Dhoofinta Xogta (Export to Markdown - `[E]`):**
   - Dhoofinta dhammaan cheatsheets-ka fayl Markdown ah (`exports/`).

6. **🚀 One-Click Kali Linux Setup Script (`setup_kali.sh`):**
   - Script hal mar Kali Linux ku shubaya dhammaan 30+ aaladood ee HAKIMIX.

1. **Make Yourself Anonymous (Qarsoodiga & OpSec)**: Proxychains, Tor Service, Macchanger, Anonsurf, DNSCrypt.
